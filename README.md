# AO3 Search Utility

This is a search utility to add onto the existing Archive Of Our Own work search page. I made it when I got fed up with searching tags and categories and ratings that either overlapped when they shouldn't or didn't when they should.

On a more personal level, however, this is a project designed to help me actually get around to learning HTML, CSS, and JavaScript properly, without the aid of website generators. My long term goal for this project is threefold:
1. Learn web design that is personal yet not complete garbage (both visually and in the backend)
2. Learn web design that is adaptive and accessible
3. Use this as a training ground for an eventual Neocities site

Now, JavaScript doesn't exactly scream accessibility. And barebones HTML and CSS doesn't either. So my eventual goal is to make this work on multiple platforms
1. Screen readers. This is an AO3 utility after all, people will be reading with them
2. Mobile platforms like phones and tablets. Most site usage these days is on mobile devices so this is important
3. Really old computers. Several of my computers access the internet through terminal browsers like w3m or on browsers that use scant JavaScript, so this is just sort of personally important

Point 3 of accessibility means that eventually I'll have to migrate away from JavaScript and towards PHP forms. But, given that this is a learning environment on top of the fact that that issue is not relevant for most users, that will probably be very low priority.
